使用流程

1打开 Minecraft Java 版，进入单人游戏，开启局域网
2在「创建房间」页面选择连接模式，软件会自动检测端口
3将 6 位房间号发给朋友，朋友在「加入房间」输入
4EasyTier 会自动组网，朋友使用显示的虚拟 IP 地址连接即可
